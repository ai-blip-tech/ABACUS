In a fresh extracted 0.14 source directory:
  patch -p1 -i /absolute/path/libredwg-0.14-empty-template.patch
  ./configure --disable-bindings --disable-docs --disable-shared --disable-write --disable-json --disable-werror --enable-release CFLAGS=-O1
  make -j4 -C src
  make -C programs dwg2dxf

unavailable. This is not an instruction to bypass dependency checks on Linux.

Select the built programs/dwg2dxf with ROOM_DWG_CONVERTER only in the isolated
candidate server environment. Do not replace the user's active preview binary.

Regression command (paths supplied explicitly, no private files bundled):
  node scripts/cad/check-decoder-regression.mjs OLD_BINARY NEW_BINARY INPUT_DWG...
The script requires identical output bytes; it reports any remaining errors.
Do not interpret identical DXF bytes as certification of every DWG feature.

User-approved policy (30 October): decoder diagnostics do not by themselves
block import if an output DXF exists and passes application parsing/conversion.
Partial output after a numeric nonzero exit can also be offered with a warning.

units still stop safely without replacing the working document. Never claim
diagnostics refer only to auxiliary data: objects/lines may be missing.
