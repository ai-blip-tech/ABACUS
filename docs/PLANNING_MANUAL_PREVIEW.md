## Поведение

- При первом открытии копируется сохранённая обмерная геометрия этого проекта.
  Пустая запись обмерного плана без стен/колонн не считается заполненной основой.
  Если её нет, открывается действительно пустой метрический документ.
- Уже начатая ручная работа не заменяется автоматически. Для старого пустого
  альбома без новых режимов можно автоматически подключить появившийся обмер.
- Верхние режимы: обмерный план, импорт ArchiCAD (явная заглушка без файлового
  ввода и преобразования), самостоятельная отрисовка.
- Обмерная и ручная основы имеют независимые сохраняемые черновики. Перед
  переключением текущий документ сохраняется через очередь с проверкой ревизии.
  При неуспехе переключение прекращается; локальный редактор остаётся на месте.
- Повторная загрузка актуального обмера требует подтверждения и сохраняет
  прежнюю копию в восстанавливаемой истории. Обмерный и монтажный этапы не пишутся.
- Левого сайдбара нет. Панель инструментов — общий `PartitionToolbar` в режиме
  монтажа. Измерение, размеры, двери/окна, цепочка перегородок, направляющие,
  привязки, ручки стен и история используют существующие общие компоненты.
- Сетка и редактирование — существующий `MeasureApp` в планировочном режиме,
  не отдельный экспериментальный solver. Неприменимые настройки недоступны.
- Мебель добавляется верхней кнопкой, каталог — отдельной кнопкой либо правым
  кликом по предмету. Выбор товара заменяет именно выбранный предмет, сохраняя
  ID, положение и поворот. Размеры берутся из каталога, где известны, иначе
  остаются явно шаблонными. Перемещение, поворот и расстояния сохранены.
- Клавиши сохранены: Ctrl/Command+C,V,Z; Shift+Z/Ctrl+Y; Escape; Delete.
  Текстовые поля и диалоги не перехватываются обработчиками геометрии.
- Компас, полноэкранный режим, сохранение, печатный альбом доступны.
  PDF использует общую обложку и рамку. Мебель печатается с поворотами,
  марками и отдельной ведомостью. Пересечения размерных подписей учитываются
  общим `dimensionLabelLayout`.
- AI-кнопки, бриф генерации и вкладки вариантов удалены с этого экрана.
  Старые AI-варианты/бриф не удалены из БД, генерация отсюда не вызывается.

## Ограничения

### Исправление категории при правом клике — 29 октября 2026

`FurnitureItem.catalogType` хранит точную категорию каталога отдельно от
символа `kind` (журнальный, обеденный столы и консоль имеют общий 2D-символ).
Каталог получает весь выбранный объект, а не только kind. Для старых объектов
без нового поля действует совместимое определение по имени предмета/товара;
геометрия и сохранённые документы при открытии не перезаписываются. Поле
проверяется серверным валидатором и сохраняется при копировании/JSON roundtrip.
В изолированной модели проверен правый клик по старому журнальному столу без
catalogType: открывается «Тип товара — Стол журнальный». Production не менялся.

### Текущая компоновка: нижняя лента — 29 октября 2026

Левый сайдбар снова удалён по уточнению пользователя. `StudioMaterialTray`
выделен непосредственно из редактора изображений и используется обоими
редакторами. Разметка карточек, фотографий, действий, удаления и горизонтальная
прокрутка не продублированы; оформление берётся из исходных studio-material
стилей. Лента расположена под рабочим модулем; клик вызывает `chooseFurniture`
и открывает параметры справа. Все экземпляры из doc.furniture отображаются
по стабильным ID, в том числе одинаковые товары и уже сохранённые предметы.
Проверено отображение 40 карточек без обрезания списка и передача ID выбора/
удаления; пользовательские предметы при UI-проверке не изменялись.

### Предыдущая компоновка со списком слева — отменена

Список размещённых предметов вынесен в отдельный левый сайдбар «Мебель на
плане». Выбор строки использует прежний `chooseFurniture`: предмет выделяется
на чертеже, параметры открываются справа над библиотекой добавления. Фото,
каталожные привязки, размеры и полный состав списка не меняются. На узком
экране список расположен под рабочим полем и имеет собственную прокрутку.
Раздел «Основа плана», его справка, перезагрузка основы и кнопки восстановления
из интерфейса удалены. Сохранённые документы и история в данных не удаляются;
переключение трёх верхних режимов и очередность сохранения остаются прежними.

### Полноценный каталог и референсы — 29 октября 2026

Правый клик по мебели содержит только «Выбрать из каталога» и «Загрузить
референс». Для каталога используется непосредственно `FurnitureCatalogPage`
из редактора изображений, без копирования фильтров/карточек и без мини-каталога.
Он открывается на весь экран в нативном modal dialog; клавиши редактора не
затрагивают план под каталогом. Escape сначала закрывает подробности товара.

Референс JPG/PNG/WEBP сохраняется с выбранным предметом в виде ограниченного
растрового превью (до 640px и 250000 символов data URL). Исходный файл не
передаётся AI. ID, положение, поворот и габариты объекта не меняются; размеры
фотографии не интерпретируются как размеры мебели. Ссылка на прежний товар
снимается, при последующем выборе товара фото-референс заменяется каталожной
привязкой. Общий лимит API на размер сохраняемого плана остаётся прежним.

ArchiCAD/PLN интеграции нет. Нет нового AI-планировщика и нет передачи данных
в OpenAI. Сохранение/редактирование не является нормативным одобрением проекта.
Косметическая сетка MeasureApp использует прежние 100 мм и основной шаг 1 м.
Сохранённая ручная планировка имеет приоритет над автоматической подменой основой.
Для production потребуются отдельная проверка актуального main, бэкап и разрешение
пользователя на выкладку. На этом этапе выкладка не выполнялась.
