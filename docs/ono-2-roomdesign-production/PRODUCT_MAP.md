# Карта ОНО 2.0 в Room Design

Дата аудита: 2026-10-13. Контур: только Room Design.

## Пользовательский интерфейс

- Единственная точка монтажа: `app/layout.tsx` → `SitewideIt`.
- Главная страница: ОНО не показывается.
- Страницы проектов, студии, шаблонов, конкретного шаблона, кабинета, админки и коммерческого предложения: используется один и тот же `ItOrb`.
- Дизайн сохраняет существующую сферу, панель диалога, состояния, адаптивную мобильную компоновку и существующие стили `app/it-orb.css`.
- Навигационные подсказки допускают только прокрутку, фокус и временную подсветку заранее зарегистрированных элементов. Нажатия и изменяющие действия не выполняются.

## API и AI-контур

- `GET /api/it`: восстановление истории текущей изолированной сессии.
- `POST /api/it`: единственная точка обращения к OpenAI Responses API.
- `DELETE /api/it`: новый диалог с удалением старой сессии текущего пользователя/посетителя.
- `GET /api/it/config`: версия ядра, runtime kill switch, навигационный манифест и состояние базы знаний.
- Основная модель: `gpt-6.1-sol`; разрешённый резерв: `gpt-6-astra`.
- Поток: NDJSON с безопасными этапами, текстовыми фрагментами, итогом и ошибкой.
- Изображение: PNG/JPEG/WebP до 8 МБ; отправляется модели с `store: false`, само изображение в истории ОНО не сохраняется.

## Память и данные

- `ono_chat_sessions`: изолирована по tenant/site/user или visitor.
- `ono_chat_messages`: хранит текст, признак изображения и проверенные карточки товаров.
- Контекст модели ограничен последними 16 сообщениями; более ранняя часть компактно суммируется локально.
- Срок памяти — 30 дней; просроченные сессии удаляются не реже одного раза в час при активности ОНО.
- Анонимный идентификатор хранится в `HttpOnly`, `SameSite=Lax`, а в production также `Secure` cookie.

## Инструменты

- Read-only поиск каталога, детали товара, сравнение и проверенная ссылка товара.
- Read-only поиск по утверждённой базе знаний Room Design.
- Инструменты генерации, изменения проекта, оплаты, списания пользовательских токенов и оформления заказа отсутствуют.
- Function Calling ограничен пятью обращениями к модели и четырьмя вызовами инструментов за один ход.

## Финансы и наблюдаемость

- `ono_cost_ledger`: одна уникальная запись на `request_id`; она же является межпроцессной блокировкой от повторного AI-вызова.
- Фиксируются модель, число вызовов, input/cached/output/total tokens, NET, действующий снимок коэффициента GROSS, итоговый GROSS и ошибка.
- Vision и Function Calling входят в usage каждого Responses API вызова и суммируются по всем вызовам хода.
- `ono_quality_events`: длительность, первый ответ, ошибки, tools, каталог, vision и handoff.
- Отчёты администратора объединяют расходы генерации изображений и ОНО без изменения действующего коэффициента.

## Граница задачи

В release входит generic SDK/iframe foundation, потому что это часть общего AI-ядра и будущей мультитенантной интеграции. При этом NORR preview, partner loader/config, allowlisted origins NORR, партнёрские инструкции и Telegram-модуль не входят. Shared NORR profile/policy остаётся неактивным для Room Design и не добавляется в Room Design prompt.
