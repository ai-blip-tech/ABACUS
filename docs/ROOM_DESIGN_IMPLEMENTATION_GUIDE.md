# ROOM Design: архитектура самостоятельного сервера

## Runtime

- Next.js 16 App Router;
- Node.js 22.13 или новее;
- SQLite из встроенного модуля `node:sqlite`;
- локальное файловое хранилище;
- PM2 и Nginx в production.

Серверные маршруты находятся в `app/api`. Единый слой данных расположен в
`lib/server-runtime.ts`; авторизация и инициализация схемы — в `lib/auth.ts`.

## Данные

Путь задаётся переменной `ROOM_DESIGN_DATA_DIR`. Внутри находятся SQLite-база
и каталог `storage`. Оба ресурса должны храниться на постоянном диске и вместе
попадать в резервные копии.

## Секреты

Секреты читаются только из переменных окружения. Клиентский код не должен
получать ключи API. Шаблон допустимых переменных находится в `.env.example`.

## Production

Стандартный цикл выпуска:

```bash
npm ci
npm run build
pm2 restart room-design --update-env
```

PM2-конфигурация хранится в `ecosystem.config.cjs`. Nginx проксирует HTTP на
локальный порт приложения. Подробная инструкция находится в `README.md`.
