# Room Design на `roomdesign.norrmobler.ru`

## Архитектура

Поддомен является второй точкой входа в тот же экземпляр Room Design. Он использует тот же Next.js-процесс, SQLite, хранилище изображений, аккаунты, проекты, историю генераций, балансы, финансовый ledger, каталог и AI-ядро ОНО. Отдельная база или копия приложения не создаётся.

`roomdesign.norrmobler.ru` определяется как вход NORR Møbler. Новая регистрация на нём получает membership существующего tenant `tenant_norrmobler`. Вход остаётся пользовательским: уже зарегистрированный участник входит с тем же email и видит тот же tenant и те же данные независимо от того, открыл он основной домен Room Design или партнёрский поддомен.

Сессионная cookie намеренно host-only, `HttpOnly`, `Secure`, `SameSite=Lax`. Общая cookie между `roomdesign.com.ru` и `roomdesign.norrmobler.ru` технически и безопасно невозможна, потому что это разные registrable domains. Поэтому автоматический перенос активной браузерной сессии между ними не выполняется: на другом домене пользователь один раз входит в тот же аккаунт по email и паролю. Данные при этом общие и не копируются.

Google Cloud Console, Google OAuth и Google callback в эту интеграцию не входят и не изменяются.

## Ссылка из карточки товара NORR

Канонический формат:

```text
https://roomdesign.norrmobler.ru/?norrProduct=<YML_OFFER_ID>#студия
```

Пример:

```text
https://roomdesign.norrmobler.ru/?norrProduct=NRM00165#студия
```

`norrProduct` — точное значение `offer id` из действующего YML-каталога NORR. Допускаются латинские буквы, цифры и символы `.`, `_`, `:`, `-`, не более 128 символов. Не следует передавать название, URL или персональные данные.

Room Design запрашивает товар через существующий `/api/catalog?ids=...`, открывает редактор, выбирает режим добавления мебели и показывает товар как референс. Генерация не запускается автоматически и токены не списываются. Пользователь загружает комнату, ставит точку и нажимает «Создать интерьер» сам.

До успешной ручной генерации идентификатор хранится в `sessionStorage` не более 24 часов. Поэтому товар сохраняется при открытии формы регистрации или входа в той же вкладке. После успешного использования запись и query-параметр удаляются.

## Серверная подготовка

1. CNAME уже указывает на `roomdesign.com.ru`; перед запуском повторно проверить A/AAAA конечного адреса.
2. Выпустить сертификат, содержащий SAN `roomdesign.norrmobler.ru`. Сейчас публичный endpoint отдаёт сертификат без этого имени, поэтому браузер блокирует HTTPS.
3. Установить отдельный server block на основе `docs/roomdesign.norrmobler.ru.nginx.conf.example`. Он направляет запросы в уже работающий процесс `127.0.0.1:3000`; второй Next.js-процесс не запускается. Обязательно сохранить `proxy_set_header Host $host`: по Host приложение выбирает tenant. `proxy_buffering off` сохраняет потоковые ответы ОНО.
4. Не менять `ROOM_DESIGN_DATA_DIR`: production продолжает использовать существующий абсолютный каталог `$HOME/ABACUS/data`. Не создавать пустую SQLite и не переносить пользовательские файлы.
5. Google Cloud Console, callback URL и Google-переменные окружения не изменять.
6. AI-ключи, billing, storage и feature flags оставить без изменений.
7. Перед перезагрузкой Nginx выполнить `nginx -t`. Конфигурацию включать только после готовности сертификата.

## Проверка перед открытием пользователям

- сертификат и цепочка действительны для нового hostname;
- `/`, `/templates`, `/_next/static/...`, `/api/health` отвечают через HTTPS;
- регистрация на поддомене создаёт NORR membership, повторный вход использует существующий аккаунт;
- вход выполняется текущей формой email/пароль; кнопки или маршруты Google для нового домена не добавляются;
- вход тем же аккаунтом на основном Room Design показывает прежние проекты, баланс и историю;
- загрузка изображения и ручная генерация работают, списание происходит один раз;
- каталог, ОНО 2.0 и product handoff работают с Origin нового поддомена;
- desktop и mobile не имеют ошибок mixed content/CORS/CSP;
- основной `https://roomdesign.com.ru` проходит неизменённый smoke-test.

## Rollback

1. Снять партнёрский server block или вернуть его на временную страницу/`444`, затем `nginx -t` и reload.
2. Откатить application release на предыдущий SHA обычной процедурой, сохранив тот же `ROOM_DESIGN_DATA_DIR`.
3. Не восстанавливать SQLite, если нет доказанного повреждения данных: добавление hostname является обратимым конфигурационным изменением и не преобразует пользовательские записи.

Изменения карточек товара выполняет команда NORR: баннер должен формировать только каноническую ссылку выше. SDK-виджет на `norrmobler.ru` для этого сценария не устанавливается.
